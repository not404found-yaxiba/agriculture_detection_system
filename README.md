## 🎯 项目概述
本项目旨在为精准农业提供一套轻量、实用的智能检测工具。系统通过深度学习模型自动识别图像中的苹果（采摘点）和杂草，并输出带定位框的可视化结果。

## ✨ 核心特性
- **双模型集成**：同时支持 **YOLOv5**（苹果检测）与 **YOLOv8**（杂草检测）
- **交互模式**：提供直观的 **Web 界面** 
- **配置驱动**：所有参数通过YAML配置文件管理
- **高可移植性**：使用相对路径解析，项目可整体移动无需修改代码
- **模块化设计**：检测器采用抽象基类设计，易于扩展新类别

## 🚀 快速开始

### 环境要求
- Python 3.8+
- CUDA 11.3+（GPU推荐）或仅CPU

### 运行步骤
1. **克隆项目**
   ```bash
   git clone 

   cd agriculture_detection_system
2. **安装依赖**
    ```bash
    pip install -r requirements.txt
3. **准备模型文件**  

    确保 models/apple/best.pt 和 models/weed/best.pt 已存在

4. **启动web应用**
    ```bash
    python web/app.py 
    ```
    访问 http://127.0.0.1:5000
